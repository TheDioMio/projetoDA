# Projeto Desenvolvimento de Aplicações

Repositório para o projeto da unidade curricular de **Desenvolvimento de Aplicações**, desenvolvido no âmbito do TeSP de **Programação de Sistemas de Informação (PSI)**.

## 📌 Descrição

Este projeto consiste numa aplicação para gestão de tarefas baseada no modelo **Kanban** (ToDo, Doing, Done). O sistema permite a atribuição, monitorização e conclusão de tarefas por equipas de programadores, com diferentes perfis de utilizador (Programador e Gestor), promovendo a organização e análise de produtividade.

## 🚀 Funcionalidades principais

- Autenticação de utilizadores com diferentes permissões
- Gestão de utilizadores (CRUD – apenas para gestores)
- Criação e atribuição de tarefas com regras de negócio específicas
- Visualização e movimentação de tarefas por estado (Kanban)
- Consulta de tarefas concluídas com tempos reais
- Exportação de tarefas para CSV
- Algoritmo de previsão de tempo com base em StoryPoints

## ⚙️ Tecnologias

- C#
- Entity Framework
- SQL Server
- Visual Studio 2022
